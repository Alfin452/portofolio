# Workspace Rules for Developer Portfolio

## Design & UI Rules
- **NO EMOJIS IN WEB INTERFACES**: Absolutely DO NOT use emojis (e.g. 🚀, 📍, 💡, 🛠️, 💻, ⚡, 🎓, 💬, ❓, 📬, ★) in any website components or UI layouts. Always use clean, professional SVG icons (inline SVG or Lucide icons) to maintain a handcrafted, senior-level frontend engineering aesthetic and eliminate any generic AI-generated feel.
